关于hexo中代码块与代码高亮的笔记。
<!--more-->

### 第一种写法：代码块
缺点是并不会在markdown中被渲染。
```
{% codeblock [title] [lang:language] [url] [link text] [additional options] %}
code snippet # 注意，写代码时不用加上方括号[]
{% endcodeblock %}
```
效果如下：
{% codeblock %}
code snippet
{% endcodeblock %}

### 第二种写法：反引号代码块
此方法在markdown中也会被渲染，极力推荐。
```
\``` [language] [title] [url] [link text] [additional options]
code snippet # 注意，写代码时要去除反义符号“\”，并且不用加上方括号[]
\```
```

效果如下：

```
code snippet
```
