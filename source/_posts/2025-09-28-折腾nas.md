## PVE(Proxmox VE)

Proxmox Virtual Environment

### iStoreOS

优点：
- 界面做的很不错
- 带有硬盘休眠功能
- 安装 openclash 很方便

缺点：
- 自带的一些软件有点问题，居然是写的脚本来安装而不是 docker，
	- 管理起来很不方便，甚至存在无法删除的问题
	- 会导致意想不到的问题，如 qbt 的设置在重启后会被覆盖
	- 脚本路径`/usr/libexec/istorec`
- 基于 openwrt，需要使用 opkg，其他环境也不是很完整
- docker 的管理面板老是爆炸


### Ubuntu

设置代理：
```bash
export https_proxy=http://<ip>:7897
export http_proxy=http://<ip>:7897
export all_proxy=socks5://<ip>:7897
```

如果有密码验证：
``` bash
export https_proxy=http://Clash:12345@192.168.50.3:7890
export http_proxy=http://Clash:12345@192.168.50.3:7890
export all_proxy=socks5://Clash:12345@192.168.50.3:7891
```

取消代理：
```bash
unset https_proxy=http://<ip>:7897
export http_proxy=http://<ip>:7897
export all_proxy=socks5://<ip>:7897
```

注意：ubuntu server 使用 `netplan` 来管理网络，而不是 `NetworkManager`

## OrangePi 安装 CasaOS

### OrangePi 相关设置

不知道为什么默认是不开启 ipv6 的，使用 `NetworkManager` 设置一下：

```bash
sudo systemctl restart NetworkManager
```

查看温度信息：

```bash
cat /sys/class/thermal/thermal_zone0/temp
```

``` bash
awk '{printf "CPU温度：%.2f°C\n", $1/1000}' /sys/class/thermal/thermal_zone0/temp
```


### CasaOS 安装与设置


安装很方便，有一键脚本（可能会有权限问题，加个 sudo 就行）：

```bash
curl -fsSL https://get.casaos.io | sudo bash
```

CasaOS 的挂载路径 `/media/devmon` 会有权限相关的问题：

```bash
sudo chmod o+rwx /media/devmon
```

docker 中的程序 (若网络为 bridge) 默认没有 ipv6，需要修改成 host 模式，此时不需要端口映射。

```bash
sudo docker exec qbittorrent ping6 -c4 test6.ustc.edu.cn
```
