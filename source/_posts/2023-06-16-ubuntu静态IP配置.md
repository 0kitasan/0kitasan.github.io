## 3.修改netplan配置
配置静态ip

``` bash
network:
  version: 2
  wifis:
    wlan0:
      access-points:
        TP-LINK #wifi名称
          password: "123456" #密码
      dhcp4: false #静态ip
      optional: true
      addresses: [192.168.0.112/24] #前者是ip，后者是子网掩码
      gateway4: 192.168.0.1  #gateway
      nameservers:
        addresses: [192.168.0.112,8.8.8.8]  #前面与ip相同即可
```


gateway查看：
``` bash
route -n
```

2024-06-12更新：在较为新版的ubuntu设备上，直接使用 `nmcli` 即可

``` bash
# 列出可用wifi
nmcli connection show

# 如果是有线连接，一般都是这个名称
Wired Connection 1

# 根据连接名称修改<name>，根据需求修改ip，注意设备的不同网段不要有冲突
sudo nmcli connection modify <name> ipv4.addresses 192.168.1.100/24 ipv4.gateway 192.168.1.1 ipv4.dns 8.8.8.8 ipv4.method manual

# 重启 NetworkManager
sudo systemctl restart NetworkManager
```
