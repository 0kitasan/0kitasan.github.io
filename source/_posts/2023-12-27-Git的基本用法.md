Git的基本用法（大部分是GPT写的）
<!--more-->
初次提交流程：

初始化
``` bash
git init
```

添加文件到本地仓库
``` bash
git add <文件名>
```
添加目录下的所有文件
``` bash
git add .
```
提交更改。m即"message"，引号中的内容用于记录提交的作用或修改
``` bash
git commit -m "your message"
```
将本地仓库与GitHub仓库关联：
``` bash
git remote add origin <GitHub仓库URL>
```
如果您要将本地的 master 分支推送到 GitHub 的 master 分支（或者是 main 分支，取决于您的设置），可以使用以下命令：
``` bash
git push --set-upstream origin master
```

或者，如果您的 GitHub 仓库的默认分支是 main，则使用以下命令：
``` bash
git push --set-upstream origin main
```

使用以下命令将本地更改推送到GitHub仓库的"main"分支（或其他主分支名称，如果不是"main"）。如果是首次推送，您需要使用-u选项：
``` bash
git push -u origin main
```

如果您已经进行了首次推送，以后只需运行以下命令即可：
``` bash
git push origin main
```
