安装 `msmtp` 邮件服务：

``` bash
opkg install msmtp
```

安装好 msmtp 后需要配置，即修改文件 `/etc/msmtprc`：

``` bash
account default
host smtp.163.com
port 25
from mail@163.com #改为自己的邮箱账户
auth login
tls off
user mail@163.com #改为自己的邮箱账户
password 12345678 #改为163令牌，而非登录密码
account default 163-mail
```

记得去 163 邮箱打开 POP3/SMTP/IMAP 服务，并获取令牌。

测试脚本：

``` bash
echo -e "Subject: Hello!\n\nHello, world!" | sendmail recipient@example.com
```
