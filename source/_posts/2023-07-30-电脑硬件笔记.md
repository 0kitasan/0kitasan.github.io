INTEL
INTEL CORE（酷睿）

intel Core i5 <font color="#0000dd">2</font><font color="#dd0000">500</font>

intel Core i7 <font color="#0000dd">8</font><font color="#dd0000">700</font>K
intel Core i9 <font color="#0000dd">9</font><font color="#dd0000">900</font>K
intel Core i5 <font color="#0000dd">10</font><font color="#dd0000">400</font>
intel Core i7 <font color="#0000dd">11</font><font color="#dd0000">700</font>
intel Core i3 <font color="#0000dd">12</font><font color="#dd0000">100</font>F
intel Core i5 <font color="#0000dd">13</font><font color="#dd0000">400</font>F
intel Core i9 <font color="#0000dd">13</font><font color="#dd0000">900</font>KF

<font color="#0000dd">蓝色</font>的表示**代数**，相当于制程工艺更新换代的级别，越大则技术越新。

<font color="#dd0000">红色</font>的表示**数值定位**，基本上数字越大，CPU性能越强。
K是可超频，F是无核显
超频会影响CPU寿命，不建议使用。

注意：
intel Core i7 <font color="#dd0000">870</font>
为第一代处理器，实际相当于 
intel Core i7 <font color="#0000dd">1</font><font color="#dd0000">870</font>

2017年后，AMD锐龙处理器对标英特尔酷睿，在这之前都被intel吊着锤
命名方式类似

G是带核显版本 X是加强版 XT表示加强版又改良加强版
X3D表示加强版又提高CPU三级缓存，在一些很吃配置的游戏里可以提升一些性能
